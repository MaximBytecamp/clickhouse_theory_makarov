# Справочник по ClickHouse

Справочник к МДК.04.01 «Разработка и защита баз данных».
Автор — Макаров Максим Николаевич.

Книга-сайт: от первой таблицы до аналитической витрины в платформе данных.
Каждая конструкция показана запросом и его настоящим выводом на стенде
и подтверждена кадром Play UI на тех же данных.

Стенд, данные и решения практик — в репозитории
[clickhouse-practice](https://github.com/MaximBytecamp/clickhouse-practice).

## Устройство

```
index.html     обложка и содержание
styles.css     типографика и наглядные блоки (общие со справочником по MongoDB)
book.js        увеличение кадров, переключатели языка и системы
temy/NN-slug/  главы: NN — номер главы без точки (0.1 → 01, 3.4 → 34)
shots/         кадры, снятые на живом стенде
tools/         съёмка кадров: shots.mjs (Play UI), mark.py (рамки и обрезка)
PLAN.md        карта книги: модули, главы, данные, принятые решения
```

Сайт статический: открывается двойным щелчком по `index.html`, публикуется
как есть, без сборки.

## Кадры

```bash
cd ~/clickhouse-practice && docker compose up -d
node tools/shots.mjs                    # все кадры из tools/shots.json
node tools/shots.mjs 03-play-check      # один кадр
python3 tools/mark.py исходный.png shots/имя.png --crop x,y,w,h --box x,y,w,h:1
```
