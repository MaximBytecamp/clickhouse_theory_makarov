## Подтверждено запуском

- `SHOW DATABASES`: восемь имён, в том числе `shop`.
- `SHOW TABLES FROM shop`: `customers`, `order_items`, `orders`, `products`, `stock`.
- `DESCRIBE TABLE shop.products`: десять столбцов; `title String`, `price UInt32`.
- `SELECT product_id, title, price FROM shop.products LIMIT 5`: пять строк и три
  столбца. На кадре Play UI указаны `5 rows in result` и `Read 21 rows`.
- `SELECT * FROM shop.products LIMIT 1`: одна строка.
- `SELECT count() FROM shop.products`: 21; добавление `LIMIT 5` сохраняет 21.
- В одном сеансе clickhouse-client: `USE shop; SELECT currentDatabase(); SHOW TABLES;`
  возвращает `shop`, затем пять таблиц магазина.
- В отдельных запросах Play UI: после успешного `USE shop` функция
  `currentDatabase()` снова возвращает `default`; `SHOW TABLES` даёт пустой список.
- Проверены ошибки для `products` в базе `default`, `shop.Products` и базы `shops`.
- Задача на `shop.orders`: описание содержит 12 столбцов, включая `status String`.
  Пробное чтение `order_id, status, total` с `LIMIT 3` возвращает три строки.
- Для `shop.products` подтверждён движок `MergeTree`; значение настройки
  `optimize_trivial_count_query` — 1. Проверка
  `EXPLAIN PLAN SELECT count() FROM shop.products` показывает
  `ReadFromPreparedSource (Optimized trivial count)`.

Важные ограничения: набор и порядок строк без сортировки не гарантированы;
`LIMIT` ограничивает результат, а не объём чтения. Поведение Play UI относится
к проверенному режиму отдельных HTTP-запросов, а не ко всем HTTP-клиентам.
Наличие таблиц в `sandbox` меняется во время практики: при проверке там были
`cart` и `cart_mem`. Общий сервер не перезапускался, данные не изменялись.

## Проверки страницы

Выполнена вычитка A–E: наглядность, последовательность, доступность,
стилистика, достоверность. Использованы существующие `review.py` и `snap.mjs`
из навыка `vychitka`, дополнительно — собственный обход страницы в Playwright.
Проверки охватывают 1280/390 px, открытые и закрытые details, изображения,
локальные ссылки, якоря, повторяющиеся id, ошибки JavaScript и увеличение кадров.

Визуальный просмотр обнаружил сжатие таблицы контекста клиентов на 390 px.
Для неё добавлено локальное вертикальное представление на узком экране.
Глобальные стили и скрипты не изменялись.
